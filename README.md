# 长乐 · 四人牌局

## 当前版本
- 横屏中式牌桌 UI，适配桌面与手机横屏
- 四人德州扑克牌型比较（七张选最佳五张）
- **无筹码下注**：玩家每局选择“留在牌局”或“弃牌”
- 弃牌触发系统飞刀判定：命中出局，落空则暂时幸存
- 所有留局玩家亮牌，最弱牌型接受飞刀判定
- 动态危险度：弃牌飞刀基础 25%，每进入新一局 +8%，每次成功淘汰 +5%，上限 75%；亮牌失败者额外 +10%，上限 85%
- 本地人机对局，三档难度

## GitHub Pages 部署
1. 解压 ZIP，把 `index.html`、`style.css`、`app.js`、`README.md` 上传到仓库根目录。
2. GitHub 仓库 → Settings → Pages。
3. Source 选择 Deploy from a branch，Branch 选择 `main`，目录选择 `/ (root)`，保存。

## Firebase 联机配置
GitHub Pages 只托管静态文件，不提供实时房间服务。联机需 Firebase Realtime Database 和匿名身份验证。
1. Firebase Console 创建项目并添加 Web App。
2. 启用 Authentication → Sign-in method → Anonymous。
3. 创建 Realtime Database。
4. 把 Firebase Web App 配置粘贴到 `app.js` 顶部 `FIREBASE_CONFIG`。
5. 配置数据库规则并部署。

**重要：当前联机代码是联机接入骨架，不是可用于公开竞技的安全服务端。** 房间状态由客户端写入，玩家底牌和判定结果不能抵御作弊；公开正式版应把发牌、飞刀随机数、轮次推进放到可信 Cloud Functions/服务器，并将私有底牌分开存储。多人房间完整的四人入座、房主开局、断线重连和服务端权限校验仍需继续完善。不要用于真钱游戏。

## 玩法
- 每人两张底牌，公共牌按翻牌、转牌、河牌一次揭示。
- 每轮玩家选择留局或弃牌；弃牌者立即接受飞刀。
- 全部行动结束后，留局者亮牌，牌型最弱者接受飞刀。
- 飞刀命中淘汰；未命中则幸存。最后一名幸存者获胜。
- 全部筹码/金币概念已移除，不涉及真钱。
